# Uniplanr

Next.js (App Router) + TypeScript rewrite of uniplanr.com, deployed on Vercel.
The legacy Laravel app lives in `legacy/` (separate local git repo, not part of this repo).

See `UPGRADE_PLAN.md` for the phased migration plan.

## Develop
```bash
cp .env.example .env.local
npm install
npm run dev
```
